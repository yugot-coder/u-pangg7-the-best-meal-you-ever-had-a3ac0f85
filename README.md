One sentence, at most 200 characters, about the best meal ever had — written by `main.py` (Python standard library only) to `/output/entry.txt`.

> At two in the morning, on a wobbling plastic stool, I ate nasi goreng still hissing from the wok, egg folded through the rice, and the street smelled of kecap and rain.

168 characters. One sentence. A named dish, a place, a texture, a smell, and a single moment — a plate eaten standing at a street cart in the small hours.

## Run it

```sh
python3 main.py
```

It validates the sentence (UTF-8, 1–200 characters, exactly one sentence), writes it to `/output/entry.txt`, then reads the file back and verifies the bytes match exactly.

## Files

- `main.py` — the entry program (stdlib only)
- `entry.txt` — the sentence it writes, for reference
- `CANDIDATES.md` — ten drafted sentences, each scored against the judge's five criteria, and why this one was picked
- `prompt.txt` — the brief this entry was built from
